# Amazon-Data-Analysis
📊 Amazon Sales Dashboard | Power BI, Excel, Power Query &amp; DAX

📌 Project Overview
This project presents an interactive Power BI dashboard designed to analyze Amazon sales data. It provides valuable insights into sales performance, product categories, brands, and regional trends through interactive visualizations. The dashboard enables users to explore key metrics, identify patterns, and support data-driven decision-making using Power BI, Power Query, DAX, and Excel.
